# Contribuindo

1. Abra uma issue descrevendo o problema ou a melhoria.
2. Crie uma branch com um nome descritivo.
3. Faça alterações pequenas e documentadas.
4. Execute `gradle --no-daemon clean build` com JDK 25 ou use a workflow do GitHub Actions.
5. Abra um Pull Request e inclua o resultado da compilação.

Nunca envie senhas reais, tokens, dados de servidores privados ou arquivos `auth.yml`/logs de auditoria.
